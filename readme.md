# 环球客 · 和AI一起学英语

面向中学生（七年级）的英语学习 Web App，同步人教版七年级上册 Starter Units。

## 功能

- 📖 **故事冒险**：中英双语故事 + 生词高亮 + 点击收藏 + 章节导航
- 📚 **学习中心**：语法微课 + 听力练习（支持 Web Speech 朗读）
- 📝 **单元测试**：词汇语法选择 + 听力理解 + 即时评分
- 📅 **每日签到**：连续签到奖励 + 连胜保护
- 🎯 **每日任务**：真实进度检测（收藏单词数、完成课数等）
- 🤖 **AI 学英语**：英语老师 / 外国笔友 / 语法专家 三种角色
- 📚 **我的词库**：阅读中收藏的单词
- 🏆 **成就徽章**：学习行为自动解锁

## 部署（Vercel）

1. 仓库结构建议：
   ```
   /
   ├── api/
   │   └── index.js          # 本仓库的 index.js
   ├── public/
   │   └── index.html        # 本仓库的 index.html
   ├── .env                  # 从 .env.example 复制
   ├── package.json
   └── vercel.json
   ```

2. 在 Vercel 项目设置中添加环境变量：
   - `OPENAI_API_KEY` 或 `MOONSHOT_API_KEY`
   - 可选：`AI_MODEL`、`OPENAI_BASE_URL` 等

3. 部署后访问即可。

## 本地测试

当前后端为 Edge Runtime + 内存状态，重启会重置进度。生产环境建议接入 Vercel KV 做持久化。
